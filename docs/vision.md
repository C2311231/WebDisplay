# Vision

## Project Overview

This project aims to be a easily deployable and scaleable digital signage platform for small organization and buisnesses. Providing easy automation, centralzed managment, and deployment of displays while remaining inexpensive, reliable, and maintainable.

## Goals

- Simple and consistant deployment on Raspberry Pi devices.
- Reliable unattended operation.
- Centralized management.
- Minimal hardware requirements.
- Offline operation.
- CEC control for automated operation.

## Target Users

This project targets small buisnesses, non-profits, and other small deployments needing a reliable and low maintance digital signage solution.

## Design Philsophy

- Reliability over features
- Simplicity over flexability
- Applience-like deployment
- Incremental Development

## Project Scope

- Display websites
- Display images
- Display videos
- Scheduling
- Remote device management
- CEC control
- Remote updates
- Multi device managment
